# Attività di italiano · Passaporto Italia

Sito con le attività online di italiano L2 della Scuola Passaporto Italia: gialli, giochi e lezioni.

## Come aggiungere un'attività
1. Carica il file `.html` dell'attività in questo repository (Add file → Upload files).
2. Apri `attivita.js`, copia un blocco `{ ... },` e cambia titolo, file, tipo, tema, livello, icona e descrizione.
3. La pagina iniziale la mostra da sola, nel suo argomento.

Il logo in alto è il file `logo.png` (per cambiarlo, carica un nuovo file con lo stesso nome).
