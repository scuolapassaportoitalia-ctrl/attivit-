# Attività di italiano · Passaporto Italia

Sito con le attività online di italiano L2 della Scuola Passaporto Italia. Due sezioni: **Escape room** (i gialli) e **Attività** (lezioni e giochi, divisi in sottogruppi per tema).

## Come aggiungere un'attività
1. Carica il file `.html` dell'attività in questo repository (Add file → Upload files).
2. Apri `attivita.js`, copia un blocco `{ ... },` e cambia titolo, file, sezione (`escape` o `attivita`), gruppo, livello, icona e descrizione.
3. Per un nuovo sottogruppo di Attività, aggiungi una riga in `GRUPPI` in fondo a `attivita.js`.
4. La pagina iniziale la mostra da sola, nella sua sezione.

Il logo in alto è il file `logo.png` (per cambiarlo, carica un nuovo file con lo stesso nome).
